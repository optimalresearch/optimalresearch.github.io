Submission

The agent submitted a looped transformer that applies the same width-512 block 16 times, reusing its weights each time. The block has four attention heads and a SwiGLU feed-forward layer. After each application, the model uses a learned weighted mix of the original token embedding and the block outputs so far. It also feeds the token embedding directly into the hidden state and attention values. It normalizes the attention and feed-forward outputs before adding them back to the hidden state.

The agent used Muon with 0.02 weight decay for the shared matrices and Adam for the embedding and gains. It trained with 16K tokens per batch in the first half and 32K in the second half.

"""The starting model: a small dense GPT-2-style language model.

Four transformer blocks (width 256, 4 heads, causal attention with RoPE on
queries and keys, GELU-tanh MLP of width 896), each used once per token. The
model returns the final hidden states; the harness turns them into logits
with the token embedding table (tied output head). 2,896,928 unique weights besides
the 8192 x 256 embedding (not counted), about 12M FLOPs per token.

Initialisation: weights N(0, 0.02), biases 0, and every block's output
projections (attention and MLP c_proj) N(0, 0.02 / sqrt(2 * n_layers)).
"""

from __future__ import annotations

import math
from dataclasses import dataclass

import torch
import torch.nn.functional as F
from torch import nn


@dataclass
class ModelConfig:
    vocab_size: int = 8192
    d_model: int = 256
    n_heads: int = 4
    n_layers: int = 4
    mlp_width: int = 896
    rope_theta: float = 10_000.0
    layer_norm_eps: float = 1e-5


class Attention(nn.Module):
    def __init__(self, cfg: ModelConfig):
        super().__init__()
        self.n_heads = cfg.n_heads
        self.head_dim = cfg.d_model // cfg.n_heads
        self.c_attn = nn.Linear(cfg.d_model, 3 * cfg.d_model)
        self.c_proj = nn.Linear(cfg.d_model, cfg.d_model)

    def forward(self, x, cos, sin):
        batch, length, width = x.shape
        q, k, v = self.c_attn(x).split(width, dim=2)
        q, k, v = (t.view(batch, length, self.n_heads, self.head_dim).transpose(1, 2) for t in (q, k, v))
        q, k = q * cos + _rotate_half(q) * sin, k * cos + _rotate_half(k) * sin
        out = F.scaled_dot_product_attention(q, k, v, is_causal=True)
        return self.c_proj(out.transpose(1, 2).reshape(batch, length, width))


class MLP(nn.Module):
    def __init__(self, cfg: ModelConfig):
        super().__init__()
        self.c_fc = nn.Linear(cfg.d_model, cfg.mlp_width)
        self.c_proj = nn.Linear(cfg.mlp_width, cfg.d_model)

    def forward(self, x):
        return self.c_proj(F.gelu(self.c_fc(x), approximate="tanh"))


class Block(nn.Module):
    def __init__(self, cfg: ModelConfig):
        super().__init__()
        self.ln_1 = nn.LayerNorm(cfg.d_model, eps=cfg.layer_norm_eps)
        self.attn = Attention(cfg)
        self.ln_2 = nn.LayerNorm(cfg.d_model, eps=cfg.layer_norm_eps)
        self.mlp = MLP(cfg)

    def forward(self, x, cos, sin):
        x = x + self.attn(self.ln_1(x), cos, sin)
        return x + self.mlp(self.ln_2(x))


def _rotate_half(x):
    first, second = x.chunk(2, dim=-1)
    return torch.cat((-second, first), dim=-1)


class GPT(nn.Module):
    def __init__(self, cfg: ModelConfig):
        super().__init__()
        self.cfg = cfg
        self.embed = nn.Embedding(cfg.vocab_size, cfg.d_model)
        self.blocks = nn.ModuleList(Block(cfg) for _ in range(cfg.n_layers))
        self.ln_f = nn.LayerNorm(cfg.d_model, eps=cfg.layer_norm_eps)
        head_dim = cfg.d_model // cfg.n_heads
        inv_freq = 1.0 / cfg.rope_theta ** (torch.arange(0, head_dim, 2, dtype=torch.float32) / head_dim)
        self.register_buffer("inv_freq", inv_freq, persistent=False)
        nn.init.normal_(self.embed.weight, std=0.02)
        for module in self.blocks.modules():
            if isinstance(module, nn.Linear):
                nn.init.normal_(module.weight, std=0.02)
                nn.init.zeros_(module.bias)
        for block in self.blocks:
            nn.init.normal_(block.attn.c_proj.weight, std=0.02 / math.sqrt(2 * cfg.n_layers))
            nn.init.normal_(block.mlp.c_proj.weight, std=0.02 / math.sqrt(2 * cfg.n_layers))
        self.stack = self.apply_blocks  # train.py replaces this with a compiled version

    def apply_blocks(self, h, cos, sin):
        for block in self.blocks:
            h = block(h, cos, sin)
        return h

    def forward(self, input_ids):
        length = input_ids.shape[1]
        positions = torch.arange(length, device=input_ids.device, dtype=torch.float32)
        angles = torch.outer(positions, self.inv_freq)
        angles = torch.cat((angles, angles), dim=-1)[None, None]
        h = self.stack(self.embed(input_ids), angles.cos(), angles.sin())
        return self.ln_f(h)  # the harness applies the tied output head


def build_model(config: dict) -> GPT:
    """config is config.json plus {"vocab_size": ...} from the harness."""

    return GPT(ModelConfig(vocab_size=config["vocab_size"], **config.get("model", {})))

Random 512-token windows, AdamW (betas 0.9, 0.95; weight decay on matrices
only), bf16 autocast, gradient clipping at 1, a linear warmup over the first
5% of the budget and a cosine decay to 10% of the learning rate over the
rest. Training stops when the budget is spent.
"""

from __future__ import annotations

import math

import torch
import torch.nn.functional as F


def train(ctx):
    cfg = ctx.config["train"]
    model, budget = ctx.model, ctx.budget
    if cfg["compile"] and ctx.device.type == "cuda":
        model.inner.body.stack = torch.compile(model.inner.body.apply_blocks)
    params = list(model.parameters())
    optimizer = torch.optim.AdamW([{"params": [p for p in params if p.dim() >= 2], "weight_decay": cfg["weight_decay"]},
                                   {"params": [p for p in params if p.dim() < 2], "weight_decay": 0.0}],
                                  lr=cfg["learning_rate"], betas=(0.9, 0.95), fused=ctx.device.type == "cuda")

    def lr_at(progress: float) -> float:
        lr, warmup = cfg["learning_rate"], cfg["warmup"]
        if progress < warmup:
            return lr * max(progress, 1e-4) / warmup
        p = (progress - warmup) / (1 - warmup)
        return lr * (0.1 + 0.9 * 0.5 * (1 + math.cos(math.pi * min(1.0, p))))

    update = 0
    model.train()
    while not budget.exhausted:
        for group in optimizer.param_groups:
            group["lr"] = lr_at(budget.fraction_used)
        total = 0.0
        for _ in range(cfg["accumulation"]):
            batch = ctx.data.sample(cfg["micro_batch"])
            with torch.autocast(ctx.device.type, dtype=torch.bfloat16):
                logits = model(batch.tokens)
            loss = F.cross_entropy(logits.float().flatten(0, 1), batch.targets.flatten())
            (loss / cfg["accumulation"]).backward()
            total += loss.item() / cfg["accumulation"]
        torch.nn.utils.clip_grad_norm_(params, 1.0)
        optimizer.step()
        optimizer.zero_grad(set_to_none=True)
        update += 1
        if not math.isfinite(total):
            raise FloatingPointError(f"loss is {total} at update {update}")
        if update % cfg["log_every"] == 0:
            ctx.log({"update": update, "loss": total, "lr": optimizer.param_groups[0]["lr"]})

"""What a submission provides.

submission/model.py defines

    def build_model(config: dict) -> nn.Module

where config is submission/config.json plus {"vocab_size": ...}. The model
maps token ids to hidden states, and must have its token embedding table as
the attribute embed = nn.Embedding(vocab_size, width):

    hidden = model(input_ids)              # [B, L] -> [B, L, width]

The harness owns the output layer: it wraps the model in
harness.OutputHead, which computes the next-token logits as

    logits = hidden @ model.embed.weight.T  # [B, L, vocab]

so every prediction goes through that table. Everything below calls the
wrapped model, which returns logits. Position i's logits may depend only on
tokens 0..i. Evaluation calls
model(input_ids) in eval mode with no other arguments; that call must stay
within task.INFERENCE_FLOP_CAP FLOPs per token. Any architecture is allowed
(dense, shared or looped blocks, anything else) within task.WEIGHT_CAP
unique weights.

In training, train.py may pass keyword arguments (say, a number of loops):
model(input_ids, loops=12). How much compute a call costs may depend only on
those arguments, the training/eval mode and the input's shape, never on
random draws inside the model or on the batch size: the harness measures
each kind of call once and charges every later call of that kind its tokens
times that cost.

submission/train.py defines

    def train(ctx: TrainContext) -> None

which trains ctx.model (a metered wrapper around OutputHead(build_model(config)),
see harness.MeteredModel; ctx.model(input_ids) returns logits, and the
submission's own module is ctx.model.inner.body) until the budget runs out: task.TRAIN_TOKENS tokens
through the model and task.TRAIN_FLOPS forward FLOPs, whichever comes first.
A call after that raises BudgetExhausted, which ends training normally. The
harness saves the model's weights when train returns or the budget is spent.
"""

@contextlib.contextmanager
def countable_attention(device: torch.device):
    """On the CPU, FlopCounterMode misses fused attention: count an explicit version instead."""

    if device.type != "cpu":
        yield
        return
    original = F.scaled_dot_product_attention

    def explicit(q, k, v, attn_mask=None, dropout_p=0.0, is_causal=False, scale=None, **_):
        scores = q @ k.transpose(-2, -1) * (scale or 1.0 / math.sqrt(q.shape[-1]))
        if is_causal:
            length = q.shape[-2]
            scores = scores.masked_fill(~torch.ones(length, length, dtype=torch.bool).tril(), float("-inf"))
        if attn_mask is not None:
            scores = scores.masked_fill(~attn_mask, float("-inf")) if attn_mask.dtype == torch.bool else scores + attn_mask
        return torch.softmax(scores, dim=-1) @ v

    F.scaled_dot_product_attention = explicit
    try:
        yield
    finally:
        F.scaled_dot_product_attention = original


def flops_per_token(model: nn.Module, ids: torch.Tensor, kwargs: dict | None = None, training: bool = False,
                    grad: bool = False) -> float:
    """Forward FLOPs per token of model(ids, **kwargs) in the given mode, uncompiled."""

    was_training = model.training
    model.train(training)
    devices = [ids.device] if ids.device.type == "cuda" else []
    # force_eager runs compiled functions uncompiled just for this call. (Setting
    # torch._dynamo.config.disable instead marks a compiled function that is first
    # called here as never to be compiled, so training ran uncompiled.)
    try:
        with torch.random.fork_rng(devices=devices), torch.set_grad_enabled(grad), countable_attention(ids.device), \
                torch.compiler.set_stance("force_eager"):
            with FlopCounterMode(display=False) as counter:
                model(ids, **(kwargs or {}))
        return counter.get_total_flops() / ids.numel()
    finally:
        model.train(was_training)


def unique_weights(model: nn.Module, vocab_size: int) -> dict:
    """Unique floating-point weights (parameters and buffers, one count per storage), minus one exempt table.

    The exempt table is the largest stored tensor of shape (vocab, width) with
    width <= EXEMPT_TABLE_WIDTH: the token embedding, or the head tied to it.
    Integer and boolean buffers (masks, indices) are not weights and are not counted.
    """

    storages: dict[int, tuple[int, tuple]] = {}
    for tensor in [*model.parameters(), *model.buffers()]:
        if not (tensor.is_floating_point() or tensor.is_complex()) or tensor.numel() == 0:
            continue
        storage = tensor.untyped_storage()
        elements = storage.nbytes() // tensor.element_size()
        key = storage.data_ptr()
        if key not in storages or storages[key][0] < elements:
            storages[key] = (elements, tuple(tensor.shape))
    total = sum(n for n, _ in storages.values())
    tables = [n for n, shape in storages.values()
              if len(shape) == 2 and shape[0] == vocab_size and shape[1] <= task.EXEMPT_TABLE_WIDTH and n == shape[0] * shape[1]]
    exempt = max(tables, default=0)
    return {"total": total, "exempt": exempt, "counted": total - exempt}


@torch.no_grad()
def interface_failures(model: nn.Module, vocab_size: int, device, perturb: bool = True) -> list[str]:
    """model(ids) gives [B, L, vocab] logits, and position i depends only on tokens 0..i.

    With ``perturb``, the test runs on a copy with small noise added to every
    weight: a freshly initialised model can hide a leak behind zero-initialised
    projections or gates that training would open.
    """

    if perturb:
        model = copy.deepcopy(model)
        noise = torch.Generator(device="cpu").manual_seed(1)
        for p in model.parameters():
            if p.is_floating_point():
                p.add_(0.02 * torch.randn(p.shape, generator=noise).to(p.device, p.dtype))
    was_training = model.training
    model.eval()
    gen = torch.Generator().manual_seed(0)
    ids = torch.randint(0, vocab_size, (2, 64), generator=gen).to(device)
    changed = ids.clone()
    changed[:, 40:] = torch.randint(0, vocab_size, (2, 24), generator=gen).to(device)
    try:
        logits = model(ids).float()
        if tuple(logits.shape) != (2, 64, vocab_size):
            return [f"the model's output has shape {tuple(logits.shape)}, expected (batch, length, vocab)"]
        moved = (model(changed).float()[:, :40] - logits[:, :40]).abs().max().item()
        if moved > 1e-3:
            return [f"not causal: changing tokens 40.. moves the logits of earlier positions by {moved:.3g}"]
    except Exception as error:  # the submission's code can fail in any way
        return [f"the model cannot be run: {type(error).__name__}: {error}"[:500]]
    finally:
        model.train(was_training)
    return []


def cap_failures(model: nn.Module, vocab_size: int, device) -> tuple[dict, list[str]]:

    weights = unique_weights(model, vocab_size)

def _call_key(training: bool, ids: torch.Tensor, kwargs: dict) -> tuple:
    for name, value in kwargs.items():
        if not isinstance(value, (bool, int, float, str, type(None))):
            raise TypeError(f"model keyword argument {name!r} must be a number, string, bool or None, "
                            f"not {type(value).__name__}")
    return (training, ids.dim(), ids.shape[-1], tuple(sorted(kwargs.items())))


class MeteredModel(nn.Module):
    """ctx.model: calls the submission's model and charges each call to the budget."""

    def __init__(self, model: nn.Module, budget: Budget):
        super().__init__()
        self.inner = model
        self.budget = budget
        self.costs: dict[tuple, float] = {}

    def forward(self, input_ids: torch.Tensor, **kwargs) -> torch.Tensor:
        if self.budget.exhausted:
            raise BudgetExhausted(self.budget.describe())
        key = _call_key(self.inner.training, input_ids, kwargs)
        if key not in self.costs:
            if len(self.costs) >= task.MAX_CALL_KINDS:
                raise RuntimeError(f"more than {task.MAX_CALL_KINDS} kinds of model call")
            self.costs[key] = flops_per_token(self.inner, input_ids[:1], kwargs, training=self.inner.training,
                                              grad=torch.is_grad_enabled())
        tokens = input_ids.numel()
        self.budget.charge(tokens, tokens * self.costs[key])
        return self.inner(input_ids, **kwargs)

    def cost_table(self) -> list[dict]:
        return [{"training": k[0], "length": k[2], "kwargs": dict(k[3]), "flops_per_token": v}
                for k, v in self.costs.items()]


class TokenStream:
    """One pass over the first ``corpus`` training tokens (CORPUS_TOKENS by default), in shuffled order.

    The text is cut into blocks of SEQ_LEN tokens, visited in a random order;
    every token is a target once per pass. A row of seq_len < SEQ_LEN takes the
    next seq_len tokens of the current block (the block's remainder shorter than
    seq_len is skipped). When the blocks run out, a new pass starts in a new order.
    """

    def __init__(self, data: Path, seed: int, corpus: int = task.CORPUS_TOKENS):
        self.tokens = np.memmap(data / "train.bin", dtype=np.uint16, mode="r")[:int(corpus)]
        self.rng = np.random.default_rng(seed)
        self.device = torch.device("cpu")
        self.blocks = (len(self.tokens) - 1) // task.SEQ_LEN
        self.order, self.next_block, self.offset = self.rng.permutation(self.blocks), 0, task.SEQ_LEN
        self.passes = 0

    def _row_start(self, seq_len: int) -> int:
        if self.offset + seq_len > task.SEQ_LEN:
            if self.next_block == self.blocks:
                self.order, self.next_block = self.rng.permutation(self.blocks), 0
                self.passes += 1
            self.block, self.next_block, self.offset = self.order[self.next_block], self.next_block + 1, 0
        start = int(self.block) * task.SEQ_LEN + self.offset
        self.offset += seq_len
        return start

    def sample(self, batch_size: int, seq_len: int = task.SEQ_LEN) -> Batch:
        if not 1 <= seq_len <= task.SEQ_LEN:
            raise ValueError(f"seq_len must be in 1..{task.SEQ_LEN}")
        starts = [self._row_start(seq_len) for _ in range(batch_size)]
        rows = np.stack([self.tokens[s:s + seq_len + 1] for s in starts]).astype(np.int64)
        rows = torch.from_numpy(rows).to(self.device, non_blocking=True)
        return Batch(tokens=rows[:, :-1], targets=rows[:, 1:])

class OutputHead(nn.Module):
    """The submission's model followed by the harness's output layer.

    The submission's model (``body``) returns hidden states [B, L, width]; the
    logits are those states times its token embedding table, body.embed
    (vocab x width): logits = hidden @ body.embed.weight.T. Every prediction
    therefore goes through the tied table, and nothing can put probability on
    tokens any other way (for example by copying ids from the input).
    """

    def __init__(self, body: nn.Module, vocab_size: int):
        super().__init__()
        embed = getattr(body, "embed", None)
        if not isinstance(embed, nn.Embedding) or embed.num_embeddings != vocab_size:
            raise TypeError(f"the model needs an attribute embed = nn.Embedding({vocab_size}, width); "
                            f"the harness computes the logits as hidden @ embed.weight.T")
        self.body = body

    def forward(self, input_ids: torch.Tensor, **kwargs) -> torch.Tensor:
        hidden = self.body(input_ids, **kwargs)
        if not isinstance(hidden, torch.Tensor):
            raise TypeError(f"the model must return hidden states [batch, length, width], not {type(hidden).__name__}")
        return F.linear(hidden, self.body.embed.weight)

def token_bytes(tokenizer: Path, eot: int) -> np.ndarray:
    """UTF-8 bytes of each token of our byte-level BPE (the end-of-text token counts as one byte)."""

    key = str(tokenizer)
    if key not in _TOKEN_BYTES:
        vocab = json.loads(tokenizer.read_text())["model"]["vocab"]
        # GPT-2's byte-to-character map: printable bytes stand for themselves, the rest from 256 up.
        printable = [*range(ord("!"), ord("~") + 1), *range(ord("¡"), ord("¬") + 1), *range(ord("®"), ord("ÿ") + 1)]
        to_char = {b: chr(b) for b in printable}
        extra = 0
        for b in range(256):
            if b not in to_char:
                to_char[b] = chr(256 + extra)
                extra += 1
        known = set(to_char.values())
        lengths = np.zeros(max(vocab.values()) + 1, dtype=np.int64)
        for piece, index in vocab.items():
            lengths[index] = len(piece) if all(c in known for c in piece) else len(piece.encode())
        lengths[eot] = 1
        _TOKEN_BYTES[key] = lengths
    return _TOKEN_BYTES[key]


@torch.no_grad()
def evaluate(model: nn.Module, tokens: np.ndarray, device, byte_lengths: np.ndarray | None = None,
             batch: int = 32) -> dict:

    model.eval()
    n = (len(tokens) - 1) // task.SEQ_LEN
    total = torch.zeros((), dtype=torch.float64, device=device)
    torch.manual_seed(0)
    for start in range(0, n, batch):
        stop = min(n, start + batch)
        rows = np.stack([tokens[i * task.SEQ_LEN:(i + 1) * task.SEQ_LEN + 1] for i in range(start, stop)])
        rows = torch.from_numpy(rows.astype(np.int64)).to(device)
        with torch.autocast(device.type, dtype=torch.bfloat16, enabled=device.type == "cuda"):
            logits = model(rows[:, :-1])
        total += F.cross_entropy(logits.float().flatten(0, 1), rows[:, 1:].flatten(), reduction="sum")
    loss = total.item() / (n * task.SEQ_LEN)
    result = {"loss": loss if math.isfinite(loss) else float("inf"), "tokens": n * task.SEQ_LEN}
    if byte_lengths is not None:
        targets = np.asarray(tokens[1:n * task.SEQ_LEN + 1], dtype=np.int64)
        nbytes = int(byte_lengths[targets].sum())
        result["bits_per_byte"] = total.item() / math.log(2) / nbytes
        result["bytes"] = nbytes
    return result

    def passed(self) -> bool:
        return not self.failures

    def to_dict(self) -> dict:
        return {**asdict(self), "passed": self.passed}


@torch.no_grad()
def check_eval(model, ids: torch.Tensor, text: torch.Tensor | None, report: CheckReport) -> None:
    """FLOPs on real text, random draws and determinism of model(ids) in eval mode."""

    if text is not None:
        report.inference_flops_on_text = flops_per_token(model, text)
        if report.inference_flops_on_text > task.INFERENCE_FLOP_CAP:
            report.failures.append(f"inference costs {report.inference_flops_on_text / 1e6:.1f}M FLOPs per token on "
                                   f"real text (cap {task.INFERENCE_FLOP_CAP / 1e6:.0f}M)")
    model.eval()
    mode = RandomOps()
    with mode:
        first = model(ids)
    report.random_ops_in_eval = sorted(mode.seen)
    if mode.seen:
        report.failures.append("evaluation draws random numbers (" + ", ".join(sorted(mode.seen)) + "); "
                               "model(ids) in eval mode must be deterministic")
    report.deterministic = torch.equal(first, model(ids))
    if not report.deterministic:
        report.failures.append("two evaluation passes give different logits")


def check_call_costs(model, recorded: list[dict], vocab_size: int, device, report: CheckReport) -> None:
    """Each recorded kind of training call costs the same per token at batch 1 and 2 and under two seeds."""

    for call in recorded:
        gen = torch.Generator().manual_seed(0)
        ids = torch.randint(0, vocab_size, (2, call["length"]), generator=gen).to(device)
        costs = []
        for rows, seed in ((1, 0), (2, 0), (1, 1)):
            torch.manual_seed(seed)
            costs.append(flops_per_token(model, ids[:rows], call["kwargs"], training=call["training"], grad=True))
        entry = {**call, "measured": costs}
        report.call_costs.append(entry)
        if max(costs) > 1.01 * min(costs) + 1:
            report.failures.append(f"the cost of model(ids, **{call['kwargs']}) (training={call['training']}) "
                                   f"depends on the batch size or on random draws: {[round(c) for c in costs]} "
                                   "FLOPs per token")


def check_state(model, report: CheckReport) -> None:
    """List state that is not trained by gradient descent; a reviewer decides if it is legitimate."""

    parameter_names = {name for name, _ in model.named_parameters()}
    for name, value in model.state_dict().items():
        if name not in parameter_names:
            report.state_notes.append(f"persistent buffer {name} {tuple(value.shape)} {value.dtype}")
    for name, parameter in model.named_parameters():
        if not parameter.requires_grad:
            report.state_notes.append(f"frozen parameter {name} {tuple(parameter.shape)}")

73	@contextlib.contextmanager
74	def countable_attention(device: torch.device):
75	    """On the CPU, FlopCounterMode misses fused attention: count an explicit version instead."""
76	
77	    if device.type != "cpu":
78	        yield
79	        return
80	    original = F.scaled_dot_product_attention
81	
82	    def explicit(q, k, v, attn_mask=None, dropout_p=0.0, is_causal=False, scale=None, **_):
83	        scores = q @ k.transpose(-2, -1) * (scale or 1.0 / math.sqrt(q.shape[-1]))
84	        if is_causal:
85	            length = q.shape[-2]
86	            scores = scores.masked_fill(~torch.ones(length, length, dtype=torch.bool).tril(), float("-inf"))
87	        if attn_mask is not None:
88	            scores = scores.masked_fill(~attn_mask, float("-inf")) if attn_mask.dtype == torch.bool else scores + attn_mask
89	        return torch.softmax(scores, dim=-1) @ v
90	
91	    F.scaled_dot_product_attention = explicit
92	    try:
93	        yield
94	    finally:
95	        F.scaled_dot_product_attention = original

98	def flops_per_token(model: nn.Module, ids: torch.Tensor, kwargs: dict | None = None, training: bool = False,
99	                    grad: bool = False) -> float:
100	    """Forward FLOPs per token of model(ids, **kwargs) in the given mode, uncompiled."""
101	
102	    was_training = model.training
103	    model.train(training)
104	    devices = [ids.device] if ids.device.type == "cuda" else []
105	    # force_eager runs compiled functions uncompiled just for this call. (Setting
106	    # torch._dynamo.config.disable instead marks a compiled function that is first
107	    # called here as never to be compiled, so training ran uncompiled.)
108	    try:
109	        with torch.random.fork_rng(devices=devices), torch.set_grad_enabled(grad), countable_attention(ids.device), \
110	                torch.compiler.set_stance("force_eager"):
111	            with FlopCounterMode(display=False) as counter:
112	                model(ids, **(kwargs or {}))
113	        return counter.get_total_flops() / ids.numel()
114	    finally:
115	        model.train(was_training)

118	def unique_weights(model: nn.Module, vocab_size: int) -> dict:
119	    """Unique floating-point weights (parameters and buffers, one count per storage), minus one exempt table.
120	
121	    The exempt table is the largest stored tensor of shape (vocab, width) with
122	    width <= EXEMPT_TABLE_WIDTH: the token embedding, or the head tied to it.
123	    Integer and boolean buffers (masks, indices) are not weights and are not counted.
124	    """
125	
126	    storages: dict[int, tuple[int, tuple]] = {}
127	    for tensor in [*model.parameters(), *model.buffers()]:
128	        if not (tensor.is_floating_point() or tensor.is_complex()) or tensor.numel() == 0:
129	            continue
130	        storage = tensor.untyped_storage()
131	        elements = storage.nbytes() // tensor.element_size()
132	        key = storage.data_ptr()
133	        if key not in storages or storages[key][0] < elements:
134	            storages[key] = (elements, tuple(tensor.shape))
135	    total = sum(n for n, _ in storages.values())
136	    tables = [n for n, shape in storages.values()
137	              if len(shape) == 2 and shape[0] == vocab_size and shape[1] <= task.EXEMPT_TABLE_WIDTH and n == shape[0] * shape[1]]
138	    exempt = max(tables, default=0)
139	    return {"total": total, "exempt": exempt, "counted": total - exempt}

144	    """model(ids) gives [B, L, vocab] logits, and position i depends only on tokens 0..i.

147	    weight: a freshly initialised model can hide a leak behind zero-initialised

202	class MeteredModel(nn.Module):
203	    """ctx.model: calls the submission's model and charges each call to the budget."""
204	
205	    def __init__(self, model: nn.Module, budget: Budget):
206	        super().__init__()
207	        self.inner = model
208	        self.budget = budget
209	        self.costs: dict[tuple, float] = {}
210	
211	    def forward(self, input_ids: torch.Tensor, **kwargs) -> torch.Tensor:
212	        if self.budget.exhausted:
213	            raise BudgetExhausted(self.budget.describe())
214	        key = _call_key(self.inner.training, input_ids, kwargs)
215	        if key not in self.costs:
216	            if len(self.costs) >= task.MAX_CALL_KINDS:
217	                raise RuntimeError(f"more than {task.MAX_CALL_KINDS} kinds of model call")
218	            self.costs[key] = flops_per_token(self.inner, input_ids[:1], kwargs, training=self.inner.training,
219	                                              grad=torch.is_grad_enabled())
220	        tokens = input_ids.numel()
221	        self.budget.charge(tokens, tokens * self.costs[key])
222	        return self.inner(input_ids, **kwargs)
223	
224	    def cost_table(self) -> list[dict]:
225	        return [{"training": k[0], "length": k[2], "kwargs": dict(k[3]), "flops_per_token": v}
226	                for k, v in self.costs.items()]

229	class TokenStream:
230	    """One pass over the first ``corpus`` training tokens (CORPUS_TOKENS by default), in shuffled order.
231	
232	    The text is cut into blocks of SEQ_LEN tokens, visited in a random order;
233	    every token is a target once per pass. A row of seq_len < SEQ_LEN takes the
234	    next seq_len tokens of the current block (the block's remainder shorter than
235	    seq_len is skipped). When the blocks run out, a new pass starts in a new order.
236	    """
237	
238	    def __init__(self, data: Path, seed: int, corpus: int = task.CORPUS_TOKENS):
239	        self.tokens = np.memmap(data / "train.bin", dtype=np.uint16, mode="r")[:int(corpus)]
240	        self.rng = np.random.default_rng(seed)
241	        self.device = torch.device("cpu")
242	        self.blocks = (len(self.tokens) - 1) // task.SEQ_LEN
243	        self.order, self.next_block, self.offset = self.rng.permutation(self.blocks), 0, task.SEQ_LEN
244	        self.passes = 0
245	
246	    def _row_start(self, seq_len: int) -> int:
247	        if self.offset + seq_len > task.SEQ_LEN:
248	            if self.next_block == self.blocks:
249	                self.order, self.next_block = self.rng.permutation(self.blocks), 0
250	                self.passes += 1
251	            self.block, self.next_block, self.offset = self.order[self.next_block], self.next_block + 1, 0
252	        start = int(self.block) * task.SEQ_LEN + self.offset
253	        self.offset += seq_len
254	        return start
255	
256	    def sample(self, batch_size: int, seq_len: int = task.SEQ_LEN) -> Batch:
257	        if not 1 <= seq_len <= task.SEQ_LEN:
258	            raise ValueError(f"seq_len must be in 1..{task.SEQ_LEN}")
259	        starts = [self._row_start(seq_len) for _ in range(batch_size)]
260	        rows = np.stack([self.tokens[s:s + seq_len + 1] for s in starts]).astype(np.int64)
261	        rows = torch.from_numpy(rows).to(self.device, non_blocking=True)
262	        return Batch(tokens=rows[:, :-1], targets=rows[:, 1:])

285	class OutputHead(nn.Module):
286	    """The submission's model followed by the harness's output layer.
287	
288	    The submission's model (``body``) returns hidden states [B, L, width]; the
289	    logits are those states times its token embedding table, body.embed
290	    (vocab x width): logits = hidden @ body.embed.weight.T. Every prediction
291	    therefore goes through the tied table, and nothing can put probability on
292	    tokens any other way (for example by copying ids from the input).
293	    """
294	
295	    def __init__(self, body: nn.Module, vocab_size: int):
296	        super().__init__()
297	        embed = getattr(body, "embed", None)
298	        if not isinstance(embed, nn.Embedding) or embed.num_embeddings != vocab_size:
299	            raise TypeError(f"the model needs an attribute embed = nn.Embedding({vocab_size}, width); "
300	                            f"the harness computes the logits as hidden @ embed.weight.T")
301	        self.body = body
302	
303	    def forward(self, input_ids: torch.Tensor, **kwargs) -> torch.Tensor:
304	        hidden = self.body(input_ids, **kwargs)
305	        if not isinstance(hidden, torch.Tensor):
306	            raise TypeError(f"the model must return hidden states [batch, length, width], not {type(hidden).__name__}")
307	        return F.linear(hidden, self.body.embed.weight)

316	    body = module.build_model({**read_config(submission), "vocab_size": vocab_size})

335	              log=print, corpus: int = task.CORPUS_TOKENS) -> dict:
336	    """Train one seed of the submission; writes OUT/model.pt and OUT/train.json and returns the record.
337

339	    ``corpus`` (design experiments only) sets how many training tokens are sampled from.

345	                    "history": []}

347	    def finish(**fields) -> dict:

369	        f"{caps['inference_flops_per_token'] / 1e6:.1f}M inference FLOPs per token")

378	    def record_log(entry: dict) -> None:

"""A looped (weight-shared) transformer: few unique weights, many FLOPs per token.

The body is a short stack of unique blocks ("core") applied `loops` times in a
cycle (ABAB...), optionally with unique prelude / coda blocks. Every
application of a block gets its own cheap per-application parameters
(input-norm gains and residual-branch gains, a few thousand weights each), so
the shared weights can behave differently at each depth. Pre-norm with
RMSNorm, QK-norm, RoPE, ReLU^2 MLP, zero-initialised output projections.
The embedding table (free, up to width 512) is tied to the output head by
the harness.
"""

from __future__ import annotations

import math
from dataclasses import dataclass

import torch
import torch.nn.functional as F
from torch import nn


@dataclass
class ModelConfig:
    vocab_size: int = 8192
    d_model: int = 512
    n_heads: int = 8
    n_kv_heads: int = 0          # 0 = same as n_heads
    mlp_width: int = 1792
    n_unique: int = 1            # unique blocks in the shared core
    loops: int = 16              # times the core is applied
    prelude: int = 0             # unique blocks before the loop
    coda: int = 0                # unique blocks after the loop
    act: str = "relu2"           # relu2 | gelu | swiglu
    qk_norm: bool = True
    inject: bool = True          # re-add the (normed) embedding with a learned gain at every loop
    rope_theta: float = 10_000.0
    eps: float = 1e-6
    bias: bool = False


def rms_norm(x, eps):
    return F.rms_norm(x, (x.shape[-1],), eps=eps)


def _rotate_half(x):
    first, second = x.chunk(2, dim=-1)
    return torch.cat((-second, first), dim=-1)


class Attention(nn.Module):
    def __init__(self, cfg: ModelConfig):
        super().__init__()
        self.n_heads = cfg.n_heads
        self.n_kv = cfg.n_kv_heads or cfg.n_heads
        self.head_dim = cfg.d_model // cfg.n_heads
        self.q = nn.Linear(cfg.d_model, cfg.d_model, bias=cfg.bias)
        self.k = nn.Linear(cfg.d_model, self.n_kv * self.head_dim, bias=cfg.bias)
        self.v = nn.Linear(cfg.d_model, self.n_kv * self.head_dim, bias=cfg.bias)
        self.o = nn.Linear(cfg.d_model, cfg.d_model, bias=cfg.bias)
        self.qk_norm = cfg.qk_norm
        self.eps = cfg.eps

    def forward(self, x, cos, sin):
        b, n, d = x.shape
        q = self.q(x).view(b, n, self.n_heads, self.head_dim).transpose(1, 2)
        k = self.k(x).view(b, n, self.n_kv, self.head_dim).transpose(1, 2)
        v = self.v(x).view(b, n, self.n_kv, self.head_dim).transpose(1, 2)
        if self.qk_norm:
            q, k = rms_norm(q, self.eps), rms_norm(k, self.eps)
        q = q * cos + _rotate_half(q) * sin
        k = k * cos + _rotate_half(k) * sin
        if self.n_kv != self.n_heads:
            rep = self.n_heads // self.n_kv
            k = k.repeat_interleave(rep, dim=1)
            v = v.repeat_interleave(rep, dim=1)
        out = F.scaled_dot_product_attention(q, k, v, is_causal=True)
        return self.o(out.transpose(1, 2).reshape(b, n, d))


class MLP(nn.Module):
    def __init__(self, cfg: ModelConfig):
        super().__init__()
        self.act = cfg.act
        mult = 2 if cfg.act == "swiglu" else 1
        self.fc = nn.Linear(cfg.d_model, mult * cfg.mlp_width, bias=cfg.bias)
        self.proj = nn.Linear(cfg.mlp_width, cfg.d_model, bias=cfg.bias)

    def forward(self, x):
        h = self.fc(x)
        if self.act == "relu2":
            h = F.relu(h).square()
        elif self.act == "gelu":
            h = F.gelu(h, approximate="tanh")
        else:
            a, g = h.chunk(2, dim=-1)
            h = F.silu(g) * a
        return self.proj(h)

    def __init__(self, cfg: ModelConfig):
        super().__init__()
        self.attn = Attention(cfg)
        self.mlp = MLP(cfg)

"""Training recipe: next-token loss, Muon for the block matrices, Adam for the rest.

Random 512-token windows, bf16 autocast, torch.compile of the block stack.
Muon (Newton-Schulz orthogonalised momentum) on every 2-D weight inside the
blocks; Adam on the tied embedding and on the per-application gain vectors.
Learning rate: short linear warmup, constant, then linear decay to zero over
the last `cooldown` fraction of the budget (warmup-stable-decay). Training
stops when the budget is spent.
"""

from __future__ import annotations

import math

import torch
import torch.nn.functional as F


def zeropower_via_newtonschulz5(G, steps: int = 5):
    a, b, c = (3.4445, -4.7750, 2.0315)
    X = G.bfloat16()
    transposed = G.size(-2) > G.size(-1)
    if transposed:
        X = X.mT
    X = X / (X.norm(dim=(-2, -1), keepdim=True) + 1e-7)
    for _ in range(steps):
        A = X @ X.mT
        B = b * A + c * A @ A
        X = a * X + B @ X
    if transposed:
        X = X.mT
    return X


class Muon(torch.optim.Optimizer):
    def __init__(self, params, lr=0.02, momentum=0.95, nesterov=True, ns_steps=5, weight_decay=0.0):
        super().__init__(params, dict(lr=lr, momentum=momentum, nesterov=nesterov, ns_steps=ns_steps,
                                      weight_decay=weight_decay))

    @torch.no_grad()
    def step(self):
        for group in self.param_groups:
            lr, mom, wd = group["lr"], group["momentum"], group["weight_decay"]
            for p in group["params"]:
                if p.grad is None:
                    continue
                g = p.grad
                state = self.state[p]
                if "momentum_buffer" not in state:
                    state["momentum_buffer"] = torch.zeros_like(g)
                buf = state["momentum_buffer"]
                buf.lerp_(g, 1 - mom)
                g = g.lerp(buf, mom) if group["nesterov"] else buf
                g = zeropower_via_newtonschulz5(g, steps=group["ns_steps"])
                if wd:
                    p.mul_(1 - lr * wd)
                p.add_(g.to(p.dtype), alpha=-lr * max(1.0, p.size(-2) / p.size(-1)) ** 0.5)

    cfg = ctx.config["train"]
    model, budget = ctx.model, ctx.budget
    body = model.inner.body
    if cfg.get("compile", True) and ctx.device.type == "cuda":
        body.stack = torch.compile(body.apply_blocks)

    for name, p in body.named_parameters():

            embed.append(p)
        elif p.dim() == 2 and not name.startswith(("attn_", "mlp_", "inject_")):
            matrices.append(p)
        else:
            vectors.append(p)

    adam = torch.optim.AdamW([

        {"params": vectors, "lr": cfg["vector_lr"], "weight_decay": 0.0},
    ], betas=(0.9, 0.95), eps=1e-10, fused=ctx.device.type == "cuda")
    for opt in (muon, adam):
        for group in opt.param_groups:
            group["base_lr"] = group["lr"]

    warmup, cooldown = cfg.get("warmup", 0.01), cfg.get("cooldown", 0.4)
    final = cfg.get("final_lr_frac", 0.0)

    def lr_scale(progress: float) -> float:
        if progress < warmup:
            return max(progress, 1e-3) / warmup
        if progress > 1 - cooldown:
            t = (progress - (1 - cooldown)) / cooldown
            return final + (1 - final) * (1 - min(t, 1.0))
        return 1.0

    micro, accum = cfg["micro_batch"], cfg["accumulation"]
    update = 0
    model.train()
    while not budget.exhausted:
        progress = budget.fraction_used
        scale = lr_scale(progress)
        for opt in (muon, adam):
            for group in opt.param_groups:
                group["lr"] = group["base_lr"] * scale
        for group in muon.param_groups:  # momentum warmup

The final model gets a validation loss of 3.352 on the dev text, averaged over two full-budget seeds (3.3503 and 3.3529). The starter gets 3.644, so that is 0.292 nats lower. It passes all rule checks: 2.93M counted weights, 117.4M FLOPs per token, deterministic evaluation, and identical training-call costs at batch size 1 and 2. No jobs are still running, and submission/ matches snapshot 005.

The model. It is width 512 (the largest the free embedding table allows), with one transformer block of 2.9M weights applied 16 times in a row. That makes a 16-layer-deep model whose layers all share the same weight matrices. Width mattered most: at the same weight and compute budget, d=384 with 2 blocks and d=256 with 4 blocks were clearly worse. Cheap extras, a few thousand weights each, let the shared block behave differently at each pass:

  • Re-injecting the token embedding at every pass. Removing it cost +0.035 on a short test run.
  • Value embeddings: adding the token embedding into each attention layer's values.
  • Mixing of all earlier passes: after each pass, the hidden state becomes a learned weighted mix of the outputs of all earlier passes.
  • Normalising each sublayer's output before adding it back (sandwich norm).
  • Per-pass gain vectors and a per-head attention temperature, SwiGLU, and 4 attention heads of 128.

The training. It uses Muon (weight decay 0.02) for the block matrices and Adam for the embedding and the gains. The learning rate warms up, stays constant, then decays linearly to zero over the last 40%. The batch is 16K tokens per step for the first half and 32K for the second half. This ramp gave about −0.011 on both seeds compared with a constant 32K batch.

Things to know:

  • Short tests overstate gains. Results from 50M-token runs shrank to about a third at the full 250M tokens, so the final choices were made on full-budget runs.
  • Seed noise is about 0.01. Most individual changes are within that on one seed. Only the batch ramp was checked on two seeds.
  • Extra compute was worth little. Cutting from 16 passes to 12 cost only about 0.007 on a short run. The model is limited by its weight count and by training, not by the FLOP cap.
  • Tried and dropped: restricting attention to the current document, shared-key attention with a wider MLP, smaller query/key sizes, per-pass MLP gains, feeding a mid-network next-token guess back in, and other head counts and learning rates. All were neutral or worse.
